## Norte visual
A referência ProHauz Plumbing é o norte contínuo do PULSE. O template adapta sua linguagem para um eletricista local brasileiro sem importar a identidade visual de VOLT ou LUMEN.

**PULSE = técnico + energético + comercial + humano + muito visual.**

Direção dominante:
- azul profundo/cobalto;
- fotografia em grande escala;
- blocos brancos alternados com faixas azuis/fotográficas;
- módulos e sobreposições controladas;
- CTA quente contrastante;
- tipografia robusta;
- ritmo visual próximo da referência aprovada.

## Arquitetura implementada
Hero → prova/atalhos → Serviços → Diagnóstico → Confiança → Trabalhos → Processo → Avaliações → Sobre → Área atendida → FAQ → CTA final → Footer.

## Guardrails
- usar a referência como sistema visual, não como clonagem literal;
- não puxar componentes ou identidade de VOLT/LUMEN;
- não inventar fatos para preencher layout;
- imagens de stock do protótipo ficam explicitamente marcadas como ilustrativas;
- avaliações/persona do demo ficam explicitamente demonstrativas;
- novos assets definitivos são refinados em `[ASSETS] PULSE — Imagens`;
- desenvolvimento final segue validação e freeze seção por seção;
- MASTER somente após o Playbook de Finalização.
